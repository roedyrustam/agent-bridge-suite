# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.2.x   | :white_check_mark: |
| < 0.2.0 | :x:                |

## Reporting a Vulnerability

The **Agent Bridge Suite** team takes the security of our episodic memory storage, adversarial heuristics, and MCP endpoints seriously.

If you believe you have found a security vulnerability:

1. **Do not create a public GitHub Issue.**
2. Please privately disclose the issue by sending an email or via GitHub Private Vulnerability Reporting.
3. Provide detailed steps to reproduce the vulnerability, including code samples or configuration where appropriate.

We will acknowledge receipt within 48 hours and work with you to triage and address the issue responsibly.
